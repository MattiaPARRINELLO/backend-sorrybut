## 🎯 Présentation
API backend pour lextension Chrome SorryBut. Gère les paiements Stripe, lauthentification OTP, et le contenu premium multilingue. Architecture modulaire avec rate limiting, JWT, et documentation API complète.

---

## ✨ Fonctionnalités
- ✅ Paiements Stripe intégrés
- ✅ Authentification OTP par email
- ✅ Contenu premium multilingue
- ✅ Rate limiting et sécurité
- ✅ API REST documentée

---

## 🚀 Installation
```bash
git clone https://github.com/MattiaPARRINELLO/backend-sorrybut.git
cd backend-sorrybut
npm install
cp .env.example .env
npm run dev
```
